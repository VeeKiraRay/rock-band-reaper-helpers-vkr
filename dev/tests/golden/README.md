# Golden charts for Difficulty > Generate

This folder is **gitignored** except for this README. It holds MIDI files whose Hard,
Medium and Easy were generated by Difficulty > Generate and then checked by hand as
correct. `dev/tests/run_generate_golden.lua` (launcher: "Generate Golden Tests", or
`lua dev/tests/run_generate_golden.lua` from the repo root) regenerates every Guitar, Bass
and Keys part from its Expert and fails when the result differs from the verified tiers -
notes, colors and lengths, and Guitar/Bass Hard's force-HOPO markers.

- **Adding a chart:** with the current version, regenerate **every** Guitar, Bass and
  Keys part (not only the one you are looking at) using the default options (Hard >
  Medium > Easy, Hard 8th runs on Auto), check them in game or by eye, export the MIDI,
  and drop it here. Every part in the file is compared, so a part left over from an older
  run fails as if the rules had changed.
- **When a test fails:** a rule change altered an approved chart. Either the change is
  right - regenerate, re-check, replace the file - or rework the rule so the verified
  song stays as it was. The failure lists rhythm, color and length differences
  separately, by bar.
- **Drums** are compared in every song, PART DRUMS and - where the song has one - PART
  DRUMS_2X (double bass pedal), whose tiers take their kicks from PART DRUMS one step up.
  Regenerate both tracks together.

An empty folder runs zero tests.
